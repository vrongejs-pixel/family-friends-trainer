# MY ENGLISH — Метод изучения английского Холмата

Персональная интеллектуальная система для последовательного изучения английского языка с нуля до уверенного общения в жизни и на работе за границей.

## Структура проекта
- `app.py` — главный файл запуска и навигация
- `curriculum/` — учебная база знаний (диагностика, словарь, грамматика, тексты)
- `data/` — хранилище прогресса пользователя
- `services/` — логика хранения данных, учёт чистого времени занятий, алгоритмы обучения
- `modules/` — учебные экраны (главная панель, диагностика, тренажёры)

## Запуск на компьютере
1. Установите Python 3.10+
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите приложение: `streamlit run app.py`
